# 🎓 大学生活模拟器

一款纯前端网页文字养成游戏：开局加点、掷骰分舍友、8 学期事件循环、隐藏门槛（人脉/运气）、小说式长链剧情、恋爱线（心动→约会→告白）、像素立绘与动作动画、成就与像素 CG、彩蛋、多结局。**零依赖、无构建、无数据库、无存档**——刷新即重开。

## ⚠️ 本地运行（必读）

游戏使用 ES Modules，浏览器禁止在 `file://` 协议下加载模块（会直接黑屏）。**必须通过静态服务器打开**：

```bash
# 方式一：npm 脚本（项目自带）
npm run serve          # 打开 http://localhost:8000

# 方式二：Python
python -m http.server 8000

# 方式三：VS Code 安装 Live Server 插件后右键 index.html → Open with Live Server
```

然后浏览器访问 `http://localhost:8000` 即可开始游戏。

## 玩法速览

1. **开局**：输入姓名 → 选难度（简单 70 点 / 普通 55 点 / 困难 40 点）→ 分配属性点（1 点财富 = ¥200）→ 🎲 掷骰随机舍友 ×2 与寝室环境（不同性格舍友解锁不同事件，寝室每周被动影响属性）。
2. **循环**：每回合 = 1 周，8 学期 × 8~10 周 ≈ 64~80 回合。每回合遇到一个事件并做出选择；期间会概率注入邂逅 / 社交 / 兴趣 / 无视等附加选项。军训、期中期末、假期、恋爱等重大事件带**小说式长链剧情**（多节点多子选项，文案随人设与结果变化）。
3. **成绩**：每学期开学基础分（按难度 25/20/17），平时自习加分，期中 / 期末强制考试，期末成绩 ≥ 60 及格；累计挂科 2 学期将被劝退。
4. **恋爱线**：破冰聚会结识 3 位可攻略人物（吃货苏苏 / 沉默陈默 / 图书馆常客林晚）→ 心动信号与恋爱事件爬好感 → 5 个约会场景（天台看星星 / 美食街逛吃 / 游乐园 / 江边夜聊 / 图书馆自习）→ 好感 ≥80 + 约会 ≥2 次后解锁告白（85% 成功，保留运气成分）。恋爱事件全部带小说式长链，文案随人物人设变化。
5. **隐藏属性**：人脉（不显示数值，决定结识人物与新选项）、运气（修正一切随机判定）——数值藏起来，但事件文案会暗示你。
6. **历史回顾**：游戏右上角随时查看本局所有选择记录（按学期分组）。
7. **结束**：4 个提前结局（破产 / 挂科劝退 / 重病休学 / 自主退学）+ 3 档毕业结局（按八学期均分）+ 毕业后去向展示（考研上岸 / 职场精英 / 躺平，纯展示无后续分支）。

## 成就与彩蛋

- **30 项成就**：完整名字 + 代码绘制的像素图标，条件隐藏在文案里，不剧透。
- **6 个彩蛋**：未解锁时完全隐藏；解锁后名字以彩色渐变展示，并触发全屏特效（伪蓝屏 / 彩虹 / 反色 / 故障抖动 / 撒花）与像素 CG。
- 小提示：**重开**按钮不会刷新页面（保彩蛋进度）；彩蛋大多和"不走寻常路"有关。

```

│   │   ├── flow.js         #   Game 状态机（回合→结算→学期→假期→毕业/提前结局）
│   │   ├── event-picker.js #   事件筛选/加权随机/强制挂点/固有注入
│   │   ├── resolver.js     #   门槛判定/效果结算/随机分支
│   │   ├── semester.js     #   学期管理/成绩结算/毕业结算
│   │   ├── random.js       #   种子随机 + 运气修正（唯一实现点）
│   │   ├── achievements.js #   成就检测队列
│   │   └── endings.js      #   提前结局判定
│   ├── data/               # 数据层（内容与引擎分离，加内容不改引擎）
│   │   ├── config.js       #   全部平衡参数唯一入口（调参只改这里）
│   │   ├── characters.js   #   14 人物 / dorms.js 6 寝室
│   │   ├── events/         #   91 事件：正常/特殊(强制挂点+长链)/固有(邂逅社交)/前置/兴趣(恋爱线)
│   │   ├── achievements.js #   30 成就（含 6 彩蛋）
│   │   ├── endings.js      #   提前结局 + 毕业变体 + 毕业后去向
│   │   ├── cg/             #   10 张像素 CG（ASCII 网格，内容作者友好）
│   │   └── icons/          #   17 个像素图标（canvas 绘制）
│   └── ui/                 # UI 层：renderer（六屏+面板）/ cg-player / effects / dom
└── tools/                  # 零依赖 Node 工具
    ├── validate.mjs        #   数据校验（ID/引用/门槛/概率/强制挂点/CG 尺寸等 12 类规则）
    ├── simulate.mjs        #   蒙特卡洛无头模拟（毕业率/结局分布/事件频率/成就达成率）
    └── smoke.mjs           #   DOM 桩冒烟测试（无浏览器跑通六屏 + 完整一局）
```

```bash
npm run validate   # 数据校验：91 事件 / 14 人物 / 6 寝室 / 30 成就 / 10 CG / 17 图标 / 129 长链 全绿
npm run simulate   # 平衡模拟：node tools/simulate.mjs [每格局数]，默认 120
npm run smoke      # UI 冒烟测试
npm run serve      # 本地静态服务器
```

## 平衡基准（simulate 实测，1440 局蒙特卡洛）

- 卷王策略（专注学习、避风险）毕业率：**简单 100% / 普通 98.3% / 困难 98.3%**；随机 / 摆烂玩法会被劝退——这就是大学。
- 学期长度中位数 9 周（8~10 达标）；每回合选项数中位 7（防选项泛滥）。
- 恋爱线（全策略合计）：**约过会 24.9% / 确定关系 13.1%**（基线 0.3% / 0.0%）；社交向玩法专注恋爱可达约过会 ~70% / 确定关系 ~50%；女宿主与男宿主恋爱线完全同等。

## 部署

### 方案 A：GitHub Pages（主推）

1. GitHub 新建仓库，推送本项目（`git init` → `git add .` → commit → push；或已安装 [gh CLI](https://cli.github.com/) 时一条龙：`gh repo create 大学生活模拟器 --public --source=. --push`）。
2. 仓库 `Settings → Pages`，Source 选 `Deploy from a branch`，分支 `main`，目录 `/ (root)`。
3. 保存后约 1 分钟生效，访问 `https://<用户名>.github.io/<仓库名>/`。
4. 全站相对路径，天然支持子路径，无需任何构建。

### 方案 B：虚拟机自托管（公网 IP）

任意能提供静态文件的 HTTP 服务即可，二选一：

```bash
# nginx（推荐，生产级）
sudo apt install nginx
sudo cp -r 大学生活模拟器/* /var/www/html/
# 访问 http://<公网IP>/

# 或轻量：Node / Python 静态服务
python -m http.server 80   # 或 node 的 npx serve -p 80
```

- 云服务器：安全组 / 防火墙放行 80/443 端口即可。
- 本地虚拟机：需在路由器做端口映射（NAT 转发公网 IP 的 80 端口到虚拟机内网 IP），或将虚拟机网络设为桥接模式直接获得局域网 IP 再映射。
- 若有域名，解析 A 记录到公网 IP；HTTPS 可用 Certbot（Let's Encrypt）免费签发。

## 常见问题

- **双击 index.html 黑屏**：ES Modules 的 CORS 限制，必须用静态服务器（见顶部）。
- **刷新页面进度没了**：设计如此——无存档，一局约 15~25 分钟，正好一口气玩完。
- **想改数值**：全部平衡参数集中在 `src/data/config.js`；改事件内容改 `src/data/events/` 下对应文件后跑 `npm run validate` 自查。
